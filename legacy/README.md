# Legacy — site atual da Selva (referência visual)

Snapshot do site publicado em selva.up.railway.app (protótipo interativo de arquivo único).
Mantido aqui **apenas como referência visual** para o novo site: tipografia, cores, grid,
elementos geométricos e cases.

**Nenhum texto deste site deve ser reaproveitado** (ver `CLAUDE.md`, "Linguagem gráfica").

Arquivos:
- `index.html` — página única com imagens embutidas (partículas 3D, carrossel de cases, prismas, adesivos, depoimentos)
- `favicon.svg`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` — ícones oficiais (S com órbita)
- `og-image.jpg` — imagem de compartilhamento
- `site.webmanifest` — manifest PWA (theme `#0B0B0C`, background `#F6F5E6`)
- `.nojekyll` — artefato do GitHub Pages

Os tokens extraídos deste site vivem em `src/styles/tokens` (Fase 1).
